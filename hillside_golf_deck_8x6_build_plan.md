# Hillside Golf Deck — 8' x 6' Build Plan (Cut List + Materials)

Scaled-down version of the locked concept in `golf_hangout_concepts.md` (originally 10'x14'), matched to the reference photos and sized to 8' long x 6' wide. Bench end holds the built-in bench with a new shelf underneath; opposite end is the turf/hitting zone with an open guard rail.

**One thing to flag up front:** this is an elevated, load-bearing structure on a slope, not a shop project — the numbers below are a solid buildable plan, not an engineered stamp. Before you cut posts, confirm frost depth / footing requirements with Uinta County if you want it permitted, and field-verify the actual rise at the stair location before cutting stringers (fake numbers there = uneven steps). Everything else is ready to build from.

**Layout (top-down):**

## Shopping List (hardware & consumables)

- 4x precast concrete deck pier blocks with adjustable post base/saddle (sized for 6x6)
- 8x joist hangers (2x8, for joist-to-beam connections)
- ~10x angle brackets / hurricane ties (post-to-beam and knee brace connections)
- 2x stair stringer angle brackets (stringer-to-deck rim)
- 12x 3/8" x 6" galvanized carriage bolts + washers/nuts (post-to-pier, handrail posts)
- Exterior/structural deck screws — 3", 2.5", and 1.5" (you likely have stock; budget ~3 boxes if not)
- Wood glue (bench joints only — everything else is screwed, not glued, for an outdoor structure)
- Sandpaper (120 grit, ease sharp edges on the bench and rail — PT lumber doesn't need a stain/finish to hold up, that's the point of using it)

## Tools Needed

Circular saw, drill/driver, jig saw (stringer notch corners only), tape measure, speed square + stair gauge attachments, string line + line level (post height layout on the slope), post level, hand tamper (pier bases), clamps.

## Build Order

1. Lay out the 8'x6' footprint with stakes and string, square it with a 3-4-5 check.
2. Set the 4 piers, string-line + level to mark each post's actual cut height.
3. Cut and set the 4 posts, attach the doubled beams.
4. Frame joists 16" O.C., add rim boards, add knee braces.
5. Lay decking.
6. Build the bench (frame → shelf cleats/boards → seat top → backrest) at the bench end.
7. Frame and hang the stairs off the long side.
8. Build and mount the stair handrail and the hitting-zone guard rail.
9. Drop in the turf mat.
