# Hillside Golf Hitting Bay / Hangout — LOCKED CONCEPT

Replaces the old lean-to fort above the cabin (Evanston, WY area — confirm frost depth/permit rules with the local county before setting final footing depth). Flat, single-level deck: hitting zone at one end, built-in bench at the other, stairs off the middle of one side. Built to survive winter parked outside, unlike the original.

Revision history: cabana-with-pergola concept (too much) -> open 12x10 deck (too plain, didn't address winter) -> 8'x10' enclosed fort with fold-down winch platform (too big/expensive) -> flat deck built with correct materials, turf removable for winter (right direction) -> this layout, based on reference photos, dialed to size. This is the version to build.

```
   |                      |

   |   edge - ball flight |
   |   toward the green)  |
   |                      |
   +------+--------+------+
          |        
          |  STAIRS (mid-side,
          |  between hitting zone
          |  and bench — keeps foot
          |  traffic out of the
          |  swing path)
          |
   +------+--------+------+
   |                      |
   |   BUILT-IN BENCH     |
   |   (spans full width) |
   |                      |
   +----------------------+
        DOWNHILL / VIEW
```

- **Overall size: 10' wide x 14' long** (recommended — down from the ~18-20' scale in the reference photo; adjust once hill measurements are confirmed below). Fits the 5x5 mat with real clearance, a bench seating 3-4, and a walking buffer between the two ends without extra unused length.
- **Hitting zone (one end):** 5'x5' removable turf mat, open rail (not solid wall) on the downhill/far edge so there's a clear sightline and ball flight toward the green.
- **Bench (opposite end):** built-in, spans the full width, solid panel front + rail like the reference photo — no separate furniture to buy or store.
- **Stairs:** off the long side, centered at the midpoint between the two ends — not tucked next to the hitting zone. Keeps anyone climbing up out of the swing zone and gives equal access to both ends.

## Framing & Materials (winter-durable — this is the fix for what wore out the old one)
- **Posts:** 6x6 PT, on precast concrete piers, stepped down the slope with post heights cut individually so the deck comes out level.
- **Footings:** precast piers on tamped soil for a lower-cost build, or poured concrete piers below local frost depth for the bombproof version — confirm frost depth with Uinta County (WY) before deciding.
- **Decking: real 5/4x6 PT deck boards or exterior-rated plywood — no OSB anywhere.** This is almost certainly what destroyed the old platform; OSB is not a decking material and fails fast under repeated wet/freeze cycles.
- **Fasteners:** coated/stainless exterior screws throughout.
- **Bench:** built from 2x PT lumber, panel front to match the reference look.
- **Rail:** 2x4 top/bottom rail, 2x2 balusters, on the open downhill edge of the hitting zone and anywhere else the floor has a real fall.
- **Turf mat:** stays removable — rolled up and stored inside (cabin/shed) over winter. This protects the one component that wears out fastest, at zero extra building cost.
- **Optional:** a tied-down tarp or vinyl deck cover over the bare decking for winter, if extra protection is wanted — not required for PT lumber, just an option.

## Rough Budget (10'x14', PT lumber throughout)
- PT framing (posts, beams, joists): ~$550-700
- Decking (5/4x6 PT): ~$450-600
- Deck piers, screws, joist hardware: ~$200-280
- Built-in bench lumber: ~$150-200
- Rail materials: ~$120-180
- Stairs (stringers, treads, rail): ~$150-250
- Turf mat (5x5): ~$100-200
- **Total: roughly $1,700-$2,400**

## Tools Needed
Circular saw, drill/driver, tape measure, speed square, string line + line level (post heights on the slope), post level, hand tamper for pier bases, clamps.

## Build Order
1. Lay out the deck footprint with stakes and string, square it up.
2. Set piers stepped down the slope, using string line + level to mark post-cut heights.
3. Set and cut posts, attach beams.
4. Frame joists 16" on-center, lay decking.
5. Build the bench at the downhill end.
6. Frame and hang the stairs off the mid-point of the long side.
7. Add rail on the hitting-zone's open edge.
8. Drop in the turf mat.

## UPDATE — final size locked at 8' x 6' (down from 10x14)

Site constraints brought the footprint down to 8' long x 6' wide. Same layout logic (bench one end, hitting zone the other, stairs off one long side) — just smaller, and the turf mat sizes down to 4'x4' to fit. One addition: the bench now has a shelf built in underneath for storage, not just a solid front panel.

Full cut list, materials, hardware, and cost estimate (~$1,050–$1,150) for this final 8x6 size: see `hillside_golf_deck_8x6_build_plan.md` in this same folder.

Still outstanding before cutting anything: actual post heights at all 4 corners (slope-dependent, field measure with string line + level) and the actual stair rise at the chosen stair location.
